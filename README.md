# abrprotowing.com
Static GitHub Pages site for ABR Pro Towing, Mississauga, Ontario.
Edit _src/site.json for business details and _src/build.py for content. Use Python 3.12+: python _src/build.py; python _src/validate.py. Commit regenerated files. Set content_updated only for meaningful content changes. Private operational instructions (public repo, excluded from Jekyll output) are in _docs/. Google review display is disabled until a verified Place ID and restricted browser key are configured. Never commit secrets. See _docs/DEPLOYMENT-AND-ROLLBACK.md.
