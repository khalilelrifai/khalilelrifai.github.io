# Performance report
Baseline: static site, no framework, existing deferred site.js, mobile CTA, lazy map frames. New review script does not contact Google unless enabled and clicked. Header asset is a 128×128 WebP derivative of supplied logo (2,370 bytes). High-resolution OG image and Apple touch icon still need owner-approved derivatives. Actual Lighthouse and Core Web Vitals were not measured in the connector environment. Before release use PageSpeed Insights mobile/desktop against main and a preview, measure LCP, CLS, TBT, accessibility and SEO; INP field data requires real visits. Targets LCP <=2.5s, INP <=200ms, CLS <=0.1, SEO/accessibility >=95, mobile performance >=90. Verify keyboard focus, 320/375/768/1280 widths, tap targets, menu and form. Do not report lab scores as field data.
