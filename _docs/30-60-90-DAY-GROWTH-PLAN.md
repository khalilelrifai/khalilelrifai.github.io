# Growth plan
Days 1–7: verify profile, review link, contact/hours/service areas, real logo assets, API billing/quotas if desired, release after tests. Verify domain in Search Console using owner-controlled DNS or approved method; submit sitemap; Bing Webmaster Tools import or verify. Create GA4 only with authorized property and privacy disclosure, track phone/text clicks, form success (not button clicks), GBP outbound and referral source; no personal data in event labels. Establish weekly baseline of impressions, clicks, indexed URLs, GBP interactions, real calls and bookings, review count, local search geo-grid, AI referrals and Core Web Vitals.
Days 8–30: request reviews uniformly, publish actual fleet/job photos with permission, create verified directory citations. Compare local search results using fixed grid, location and query.
Days 31–60: review Search Console queries and conversions; improve pages that underperform; add useful verified local content only if needed. Avoid link schemes and duplicate location pages.
Days 61–90: compare rolling 28-day and baseline metrics; track Google Maps and ChatGPT discovery separately; refine based on qualified inquiries and real conversions, not vanity ranking. No ranking guarantees.
