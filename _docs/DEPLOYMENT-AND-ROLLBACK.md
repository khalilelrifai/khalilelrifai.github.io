# Deployment
Python 3.12+; run python _src/build.py and python _src/validate.py; node --check js/google-reviews.js. Feature branch workflow validates and regenerates tracked output without touching main; PR checks require generated files match source. Inspect GitHub Actions and PR exact head, preview through local python -m http.server 8000 or authorized preview hosting. Verify Google links and real form delivery with owner consent; confirm all service information. Do not merge before acceptance/authorization. After merge, inspect Pages deployment, HTTPS canonical, sitemap, robots, pages and mobile CTA. Roll back with revert of the merge commit (do not force push). Old pages use HTML redirect stubs, not HTTP 301; preserve URLs. Docs are under _docs so Jekyll excludes them from the published site.
