# Google review integration
The browser module uses Maps JavaScript API and the new Place class. It only fetches on explicit user click and only when enabled with a verified ID and key. Rating/count and returned reviews are rendered with author attribution, Google Maps text attribution, source links, and policy link. No persistent storage, scraping, fake reviews, or self-serving review markup.
Owner: create Google Cloud project, enable billing, Maps JavaScript API and Places API (New); obtain Place ID through official methods; verify correct entity and service-area listing availability. Create a browser key restricted to HTTPS referrers https://abrprotowing.com/* (add www only if used) and required APIs. Set quotas and budget alerts (alerts are not spending caps). A browser key is public by design; never supply an unrestricted key or OAuth credentials. Set google_reviews.enabled, place_id, browser_key in site.json, rebuild and verify on approved host. If service-area business is not retrievable or API fails, keep profile fallback only. Test attribution and review links against current policy before enabling. Data is fetched when clicked, not push-real-time; Google decides returned review selection. Owner-only review notifications require separate approved GBP OAuth and Pub/Sub; not used for public redistribution.
Docs: https://developers.google.com/maps/documentation/javascript/place-reviews ; https://developers.google.com/maps/documentation/javascript/policies ; https://developers.google.com/my-business/content/notification-setup .
